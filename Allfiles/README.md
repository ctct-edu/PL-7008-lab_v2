# サンプルデータの定義

すべて新規作成した架空データです。経費の金額は日本円です。教材の検証用に固定値を使い、為替レートから換算していません。

## 経費申請

Excelのシートは「経費申請」、テーブルは `Expenses`、データは8行です。列名は参照の安定性のため英数字にしています。

| 列 | 意味 | Dataverseで確認する型 |
|---|---|---|
| ClaimId | 申請番号 | テキスト |
| ExpenseTitle | 経費名 | テキスト。プライマリ名列として使用可能 |
| ExpenseType | 交通費、宿泊費、食事代、会議費、事務用品費 | テキスト |
| ExpenseDate | 経費発生日 | 日付のみ |
| SubmissionDate | 申請日 | 日付のみ |
| ApprovedDate | 承認日。未承認は空欄 | 日付のみ |
| AmountRequestedJPY | 申請額（円） | 整数または小数。通貨列にしない |
| AmountApprovedJPY | 承認額（円） | 整数または小数。通貨列にしない |
| ExpenseStatus | 申請済み、審査中、承認済み、却下 | テキスト |

整数を通貨列にしないのは、用意済み環境の基準通貨を変更せず円の値を扱うためです。EXP-006の承認額0は審査中の未確定値です。EXP-007は申請6,000円に対して規程上限5,000円を承認した例です。

| 分類 | 件数 | 申請額合計（円） | 承認額合計（円） |
|---|---:|---:|---:|
| 交通費 | 2 | 26,420 | 26,420 |
| 宿泊費 | 2 | 21,800 | 21,800 |
| 食事代 | 2 | 3,000 | 1,200 |
| 会議費 | 1 | 6,000 | 5,000 |
| 事務用品費 | 1 | 2,400 | 2,400 |
| 合計 | 8 | 59,620 | 56,820 |

## 運用タスク

Excelのシートは「運用タスク」、テーブルは `Tasks`、範囲はA1:F5です。先頭行はヘッダーです。

| 列 | 意味 |
|---|---|
| Reference | タスク番号 |
| Title | 日本語のタスク名 |
| Description | 日本語の説明 |
| RequestedBy | 依頼部署 |
| Priority | フィルター用のコード。High、Medium、Low |
| Status | 未着手、対応中、完了 |

優先度コードを日本語化すると、フローと質問の選択肢も変更する必要があります。この教材では `High = 高`、`Medium = 中`、`Low = 低` としてコードを維持します。Mediumで取得するのは次の2件です。

- OPS-002: バックアップ結果の確認
- OPS-004: 障害報告書の作成

Highも2件、Lowは0件です。ファイル内の説明用の追加行や合計行をテーブルに入れないでください。
