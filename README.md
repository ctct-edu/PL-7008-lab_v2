## 注意事項

ラボ環境は、研修・学習を目的として提供するものです。

機密情報（個人情報、営業秘密、機密文書等を含みますがこれに限りません）を入力・アップロードされた場合、その情報が第三者に漏洩したことによって生じるいかなる損害についても、当社は一切責任を負いません。

機密情報をラボ環境に入力・アップロードしないよう、十分ご注意ください。
